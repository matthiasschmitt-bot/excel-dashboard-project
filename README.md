# 📊 Abschlussprojekt – Excel Dashboard (Januar 2026)

Dieses Projekt ist ein vollständiges Excel-Dashboard, das im Rahmen meines Abschlussprojekts (Januar 2026) entstanden ist.  
Es visualisiert wichtige Geschäftskennzahlen und zeigt, wie man Daten strukturiert, analysiert und für Entscheidungen aufbereitet.

---

## 🎯 Projektziel

Ziel des Projekts war es, aus Rohdaten ein **professionelles, interaktives Dashboard** zu erstellen, das:

- zentrale KPIs übersichtlich darstellt  
- Trends und Entwicklungen sichtbar macht  
- Filtermöglichkeiten bietet (z. B. Zeitraum, Kategorien, Regionen)  
- für Management-Entscheidungen geeignet ist  

---

## 🛠️ Verwendete Tools & Techniken

- **Microsoft Excel**
- PivotTables  
- PivotCharts  
- Slicer / Filter  
- Formatvorlagen  
- Dynamische Diagramme  
- Formeln wie:  
  - `SUMME()`  
  - `WENN()`  
  - `SVERWEIS()` / `XVERWEIS()`  
  - `SUMMEWENN()`  
  - `TEXT()`  
  - `DATUM()`
